# Instrucciones de commit sugeridas - Semana 12

Desde la carpeta del proyecto:

```bash
git status
git add .
git commit -m "feat(tickets): integra flujo principal semana 12"
```

Nota:
- El proyecto venia con cambios de semanas anteriores sin commitear.
- Tambien se dejo preparada la salida de archivos __pycache__ del control de versiones.
- Revisar `git status` antes del commit para confirmar que se incluyen los avances deseados.
