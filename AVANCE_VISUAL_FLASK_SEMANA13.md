# Actualizacion visual Semana 13

Se agrego una interfaz web minimalista con Flask para que el proyecto pueda demostrarse de forma visual.

## Archivos agregados

- `app.py`
- `requirements.txt`
- `templates/base.html`
- `templates/dashboard.html`
- `templates/tickets.html`
- `templates/ticket_detalle.html`
- `templates/usuarios.html`
- `templates/catalogos.html`
- `static/styles.css`

## CRUD visual incluido

- Tickets: crear, listar, consultar, actualizar y eliminar.
- Usuarios: crear y listar.
- Catalogos: crear y listar.

## Justificacion de alcance

La vista Flask se considera integracion visual para demo y preparacion de entrega. No incluye funciones grandes como autenticacion completa, permisos reales, asignacion avanzada, reportes o adjuntos.
